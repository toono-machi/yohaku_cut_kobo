# 余白カット工房｜台詞音声の無音一括カット

WAV・MP3音声の冒頭と末尾を自動検出して一括カットする、ゲーム制作者向けブラウザアプリです。

## 使い方

1. `index.html` をブラウザで開き、WAV / MP3 をまとめて読み込みます。
2. 左パネルで感度（dB）、冒頭と末尾の余白、検出する最短時間を調整します。
3. リストの音声をクリックすると波形と前後のカット量を表示します。
4. 「カット前」「カット後」で試聴できます。波形の縦線をドラッグ、または開始・終了時間（ms）を直接入力することで個別の手動調整が可能です。
5. WAV / MP3 を選び、個別保存またはZIP一括保存します。

## GitHub Pages への公開

1. GitHubで新しいパブリックリポジトリを作ります。
2. `index.html` をリポジトリのルートにアップロードします（`README.md` は任意）。
3. リポジトリの **Settings → Pages** から、**Deploy from a branch**、ブランチ **main**、フォルダ **/(root)** を選びます。
4. 公開された Pages のURLにアクセスします。

HTML 1ファイルのみで動作し、ビルドやサーバー側の処理は不要です。

## 仕様・注意

- 入力：WAV / MP3（ブラウザのデコーダーが対応するもの）。
- 出力：WAV（16bit PCM） / MP3（128・192・256・320 kbps）。
- MP3出力には `lamejs`（CDN読み込み）が必要で、ネット接続が必要です。WAV出力は外部ライブラリ不要・オフラインでも動作します。
- 無音判定は10msごとの音声RMS音量と、しきい値を超える最短持続時間で行います。途中の無音は切らず、先頭と末尾だけをカットします。
- 声が検出できなかった音声は誤削除防止のため原音のまま保存し、一覧に「無音判定不可」と表示します。波形で手動調整できます。
- WAVおよびMP3のサンプルレートは読み込んだ後のWeb Audio APIのレートが基準です。オリジナル音源のエンコード済みサンプルレートと異なる場合があります。
- 複数ch入力の書き出しは最大2ch（モノラル／ステレオ）です。
- MP3では圧縮エンコーダー固有の遅延・パディングが発生する場合があるため、サンプル精度のカットが必要な場合はWAVをお使いください。
- 音声はすべてローカルのブラウザで処理し、外部へアップロードしません。MP3エンコード用のJavaScriptのみCDNから取得します。
- 大容量・大量ファイルの処理では、ブラウザメモリを多く使用する場合があります。
- カット設定はブラウザのローカルストレージに保存されます。読み込んだ音声自体は保存されません。

## MP3エンコードで使用する外部ライブラリ

[lamejs 1.2.1](https://github.com/zhuker/lamejs)（LGPL-3.0）をCDN経由で読み込みます。ライブラリはZIP内に同梱していません。
